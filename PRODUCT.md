# Why I built this

I already had a portfolio and it did the job, but it did not say much about how I like to build things. A list of projects tells you what I finished. It does not tell you what it feels like when I am the one making something.

So I built the one I actually wanted. You travel through this one. The train is the menu, the sea is the backdrop, and every section is a place you go to instead of a block you scroll past. I am after the kind of site that speaks a feeling into you before it has told you a single fact about me.

It is also how I learn. I try the hard version first, see where it breaks, and build the next one on what that taught me. Break things, learn from them, build better.

## My design rules

- One idea, carried all the way through. Everything here is the train, the sea and paper.
- Travel, not navigation. You get somewhere, and the fog covers the change.
- Never blank the page to load something. A small plant grows in the corner instead.
- If the 3D cannot run, every word is still there and still reachable.
- The keyboard reaches everything the pointer reaches.
- No motion nobody asked for. Reduced motion gets the same places with the travelling taken out.
- The page and the world share one palette and one set of hands, so nothing looks pasted on.
- Nothing hand modelled. If it stands in the world, it is written in code and baked.
- The words are mine. Plain, a bit warm, no filler.
- Built for a phone, not merely surviving on one.
